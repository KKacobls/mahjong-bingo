# 麻將賓果 v2 物理版

網址：https://kkacobls.github.io/mahjong-bingo/v2/

原版位於 ../index.html，v2 獨立目錄不覆蓋原有網站。
功能：每局 6～30 張、聽牌後繼續抽 5 張（設定可調）、補摸沒中的牌重力落下、在上方和底盤左右兩側直接點真實牌背摸牌、手機晃動攪動剩餘牌池。晃動不更改抽牌結果；iOS Safari 必須按鈕授權感應，且網站使用 HTTPS。

v2/index.html、v2/style.css、v2/app.mjs 為前端原始碼。為避免重複資產，v2/app.mjs 引用 ../dist 的計算、紀錄、音效、碰撞模組以及牌圖。請使用 GitHub Pages 或本地 HTTP server 測試，不要直接使用 file:// 開啟。

## v2.1：左右牌池與完整手牌

手機版現在將原本的上方牌池延伸成環繞 6×6 底盤的 U 字形牌池，不會生成額外的隨機抽牌按鈕。36 張牌背可分散到上、左、右三個區域，並且保持同一套抽牌牌序。碰撞引擎會將牌背推離底盤的障礙區。

手牌依未擺放張數動態增加 1～3 排高度，讓 6～30 張起始牌（以及最多 5 張補摸牌）可以全部顯示，不需擠在單一短的手牌區塊中。
