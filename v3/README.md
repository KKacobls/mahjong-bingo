# 麻將賓果 v3 · U 型碰撞牌池與手機動作感測

線上入口：https://kkacobls.github.io/mahjong-bingo/v3/

此版本是獨立的單檔離線 HTML，使用已嵌入的圖檔與腳本。不會覆蓋首頁舊版與 /v2/。

- 初始可選摸牌張數 6～30，牌桌「−／＋」快捷切換。
- 聽牌觸發非聽牌線牌面的自然落牌；補摸上限預設五張，另可由玩法設定改變。
- 牌池延伸在底盤上方、左右兩側，物理碰撞不會穿入底盤。
- 裝置支援時可按「搖晃」允許手機動作感測器，傾斜可滑動牌背，搖晃可攪拌；不影響抽牌隨機性。
- 含 iOS Safari 動作感測器首次授權，須 HTTPS。若裝置不支援感測器，仍可手動洗牌。
