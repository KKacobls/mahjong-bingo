# 麻將賓果 v3 · 單聽牌只留下該條連線

線上入口：https://kkacobls.github.io/mahjong-bingo/v3/

v3 現在釐清了「落牌」的正確玩法：

1. 先摸滿設定的張數（例如 **15 張**），把已摸的牌放到 6×6 底盤。
2. 若已連線（6 張）直接中獎；若同時聽兩個以上不同缺牌，依原設定免費重來。
3. **只有單聽一張牌（5 缺 1）時**，在所有可能的連線中固定選定一條 6 格連線。
4. **該連線的五張已摸牌和缺的一張維持原位置**；其餘 **30 格的牌全部向下掉出畫面**，不只是去掉未摸牌，也包含其他已摸到但無關的牌。
5. 顯示「單聽」與目標牌名，補摸預設 **5 張**，補中免費重來；沒有聽牌則不落牌。
6. 這個動畫只影響顯示，不變更牌序、統計、補摸結果和歷史紀錄。

版本保留：`backup/2026-10-28-v3-before-single-wait-fall` 可還原修改前 v3；首頁與 v2 均不變。

v3 也支援 6～30 張、上方「−／＋」調整、U 型牌池、左右牌池與 iOS/Android 動作感測器授權。


## 固定機率表（2026-10-28）

- 「機率」視窗不再執行每次 300,000 次 Monte Carlo 模擬，也不會等待 Worker 完成；打開即讀取預先存好的數據。
- 比較表支援 6～30 張。直接中獎率由 14 條線的容斥原理精確算出，再固化數值。
- 免費重來率使用固定種子、2,000,000 副完整隨機排列的離線樣本統計。它是「估計」，不是精確機率；最終中獎率根據直接中獎率與重來率推得。
- 預先建立 0～35 張補摸與雙聽直接重來開／關的組合，變更玩法時只切換查表，不重新模擬。
- v2 的固定數據在 `v2/fixed-probabilities.mjs`，v3 為單檔 HTML，直接內嵌相同數據。
