# 麻將賓果

純前端麻將連線：散牌碰撞洗牌、手動選牌／拖拉、逐張自動擺牌與機率、期望值計算。支援手機與黑色背景。

## 開啟網站

GitHub Pages 請設為：Settings → Pages → Deploy from a branch → main → /(root)（選 /docs 也可）。

## 本機使用

直接開啟 `docs/index.html`。所有圖片、程式與背景計算都內嵌在同一個 HTML。

## 規則與牌面

- 共 36 張：34 種一般麻將，加一張普通五萬及一張普通五筒。追加兩張翻面後標示 ②，對應獨立底盤格；所有牌背一致。
- 不使用紅五萬、紅五筒、紅五索。
- 原始摸牌連線領一份獎品；聽兩張以上可設定免費重來；補摸命中只重來。
- 直接中獎率使用包含排除原理；重來率使用瀏覽器內 30 萬次模擬。期望值是假設各局重新洗牌、免費重來無上限的長期平均。
- 洗牌為二維旋轉矩形碰撞模擬；視覺動作與實際牌序分開，開始選牌前牌序已固定。

## 開發

無外部套件依賴。

`node --test tests/*.test.mjs` 執行計算與碰撞測試。

`node build.mjs` 從 `dist/` 原始碼產生 `index.html` 和 `docs/index.html`。

牌圖採用使用者提供的 FluffyStuff 麻將素材，CC0 授權，見 `LICENSE-tiles.md`。
