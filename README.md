# 麻將賓果

純前端麻將連線，支援碰撞洗牌、拖拉、逐張自動擺牌、手機版及黑色背景。

## 遊玩與紀錄

- 36 張不同牌：34 種一般牌，加紅五萬、紅五條。
- 底盤預設每次開啟及每局打亂，設定勾選「不打亂」才固定順序。
- 按付費按鈕記錄支出並增加局數，預設 6 局 100 元，可在右上角設定修改。這是本機模擬記帳，沒有金流。
- 開始摸牌扣一局，免費重來不扣付費局數。自動跑牌用完局數會等候續買。
- 即時統計顯示完成局數、中獎次數、實際中獎率、累計支出、平均中獎花費及支出曲線。
- 機率只在右上角「機率」開啟後顯示，可比較摸牌張數。
- 設定、統計及最近 100 局只存於瀏覽器 localStorage，可清除。歷史重現保留底盤及牌序。

## 開啟與開發

網站：https://kkacobls.github.io/mahjong-bingo/

可直接開啟 index.html 或 docs/index.html；程式與圖片均內嵌，無外部套件依賴。

執行 `node build.mjs` 從 dist 產生兩份 HTML；執行 `node --test tests/*.test.mjs` 驗證計算、帳務、儲存與洗牌碰撞。

GitHub Pages 使用 main 分支根目錄。牌圖為使用者提供的 FluffyStuff 麻將素材，CC0，見 LICENSE-tiles.md。
